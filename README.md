# ORBIT（オービット）店舗管理システム

自店の公式サイトとポータルサイトを1か所で管理する管理画面です（フォルダ名は pertal-cms）。設計書「ポータル連動CMS 設計書（Mr.Venreyインスパイア）」のステップ1（管理画面の土台）です。

## はじめて動かすとき（Macのターミナルで）

```bash
cd ~/pertal-cms
npm install        # 部品のインストール（最初の1回だけ）
npm run setup      # DBの作成とデモデータの投入（最初の1回だけ）
npm run dev        # 起動
```

ブラウザで http://localhost:3000 を開くと、ログイン画面が出ます。

- 開発用の初期ログイン：**ID 1001 ／ パスワード orbit-demo**
- 一度ログインすると、次からは「Biollante 梅田店 様」と店舗名が出て「ログイン」だけで入れます（パスワードは聞かれます）。ほかのIDで入るときは「別アカウントでログイン」。

- DBは手元の `.data` フォルダに作られます（Neonの設定は不要）。
- ID・パスワードを変えるときは、`.env.example` をコピーして `.env.local` を作り、`ADMIN_ID` と `ADMIN_PASSWORD` を書きます。本番（npm run build / start）では `ADMIN_PASSWORD` が必須です。
- デモデータを最初からやり直したいときは、`.data` フォルダを削除してから `npm run setup` を実行します。

## 公式サイト（Biollante）とつなぐ

1. Biollante の `.env.local` に `OFFICIAL_API_KEY="24文字以上の合言葉"` を書いて、Biollante を起動し直す（Vercel では環境変数に同じものを登録）
2. ORBIT の「連携ポータル → オフィシャル（公式サイト）」に、BiollanteのURL（Macで試すなら http://localhost:3001 など）と同じ合言葉を入れて「保存して接続テスト」
3. 「公式サイトから取り込む」で、Biollanteの女性・出勤・今日の待ち時間をORBITへ写す（初回や接続先を変えたときは「ORBITの女性を全員入れ替える」にチェック）
4. あとはORBITで女性・出勤・即姫を保存すると、Biollanteに自動で届きます。結果は「配信ログ」で確認

- ORBITで女性を削除しても、Biollante側では「非公開」になるだけです（写真などは消えません）
- 写真・Q&A・オプションなど、Biollante独自の項目はORBITからは変わりません


## 女性プロフィールの項目について

- 項目名・文字数・必須/推奨は Mr.Venrey の「女性プロフィール編集」に合わせています（`src/lib/castFields.ts`）
- ポータルごとの専用項目は `src/lib/sites.ts` にまとまっています。サイトを増やすときはここに足すだけで、編集画面に項目が出ます
- どのサイトの項目を出すかは「連携ポータル → 連動先サイト」で選びます
- 写真は手元では `.data/uploads` に保存されます（本番は Vercel Blob。`BLOB_READ_WRITE_TOKEN` を設定）

## しくみ

- Next.js（App Router）＋ Drizzle ORM
